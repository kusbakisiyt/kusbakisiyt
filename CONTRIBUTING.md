# Contributing

Contributions that improve stability, documentation, cross-platform support, subtitle timing, accessibility or build reliability are welcome.

## Before opening a pull request

1. Keep changes focused and explain the user-facing effect.
2. Run the source-quality checks described in `docs/BUILDING.md`.
3. Do not commit game BIN/ISO/CUE files, PlayStation BIOS files, emulator binaries, xdelta binaries, commercial artwork, dialogue dumps, scene captures or other copyrighted game assets.
4. Do not weaken the source-BIN hash validation or output verification without a documented technical reason.
5. Preserve Windows and Linux behavior where possible.

By submitting a contribution, you agree that your contribution may be distributed under the MIT License used by this repository.
