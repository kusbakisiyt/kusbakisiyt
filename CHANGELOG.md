# Changelog

## 1.1.3 — 2026-07-27

- Added a multilingual Turkish, English and German launcher flow.
- Added verified xdelta provisioning for supported SLES-02886 and SLES-02888 source images.
- Added source-size and cryptographic-hash validation before patching.
- Added output verification and atomic replacement to protect the original source image.
- Improved Windows and Linux subtitle-overlay packaging.
- Improved Linux X11/XWayland handling and process cleanup.
- Updated packaging scripts to exclude game BIN and BIOS files.
- Published the original project code under the MIT License in a separate source release.
