# External Runtime Assets

The complete end-user build uses a separate runtime asset directory named `kaynaklar`. Its copyrighted and third-party contents are not part of this source archive.

Expected high-level layout:

```text
kaynaklar/
├── duckstation/
│   └── bios/          # distributed empty; user supplies their own BIOS
├── overlay/           # subtitle and scene-recognition runtime data
├── oyun/              # distributed empty; user supplies their own BIN
└── provisioning/      # generated by the build scripts
```

Never commit game files, PlayStation BIOS files, save data or personal configuration to the public source repository.
