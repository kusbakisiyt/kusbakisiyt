# GitHub'a Yükleme

Bu ZIP dosyasını tek parça olarak kaynak kod yerine koymak yerine:

1. ZIP'i bilgisayarında çıkart.
2. İçindeki `spider-man-2000-tr-en-de-localization-source-v1.1.3` klasörünü aç.
3. Klasörün **içindeki bütün dosya ve klasörleri** proje deponun ana dizinine yükle.
4. Paket özellikle `README.md` içermiyor; böylece mevcut ana sayfan değişmez. `SOURCE_CODE.md` kaynak kod açıklamasıdır.
5. `docs/README_SOURCE_SECTION.md` içindeki kısa bölümü mevcut ana `README.md` dosyana ekle.
6. En azından `LICENSE`, `NOTICE.md`, `src/`, `docs/`, `.github/`, `requirements*.txt`, `.gitignore` ve `.gitattributes` dosyaları depoda görünür olsun.
7. Commit mesajı olarak şunu kullanabilirsin: `Publish v1.1.3 source code under MIT license`

Mevcut Windows/Linux indirme paketlerine dokunman gerekmez. Bu kaynak kod paketi onların yanında ayrı olarak yayımlanır.
