# Source Package Scope

This package is intentionally separate from the published end-user installer.

## Included under MIT

- Original Python launcher and provisioning code.
- Original Windows/Linux subtitle-overlay code.
- Original build and packaging scripts.
- Original documentation and repository configuration.

## Excluded

- Game BIN/ISO/CUE files and PlayStation BIOS files.
- Delta patch payloads and verified translated game outputs.
- Subtitle databases derived from game dialogue.
- Scene screenshots, templates and caches derived from game footage.
- DuckStation and xdelta3 binaries or source.
- Spider-Man artwork and installer branding.
- Compiled EXE, AppImage, DEB and installer output.

The exclusions prevent the MIT license from being misunderstood as a license to third-party content and keep the source repository suitable for public inspection and contribution.
