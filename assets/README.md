# Branding Assets

Branding artwork used by the published installer is intentionally not included in this MIT-licensed source archive.

For a local build, provide assets you have permission to use with these filenames:

- `spiderman.png` — 256×256 Linux application icon.
- `spiderman_ico.ico` — Windows launcher and installer icon.

These files are ignored by Git and are not covered by this repository's MIT License unless their owner explicitly licenses them separately.
