# Security Policy

## Supported version

Security and data-loss fixes are currently accepted for the latest 1.1.x source release.

## Reporting a vulnerability

Use GitHub's private vulnerability-reporting feature from the repository's **Security** tab when available. Do not publish personal information, game files, BIOS files, access tokens or exploit details in a public issue.

For ordinary crashes and compatibility problems, use the bug-report template and remove private paths or account details from logs before posting.
